# BarberKing

> Modern responsive landing page for a barbershop.

## 📖 About the Project

BarberKing is a modern landing page concept designed for a barbershop.

The project focuses on presenting the brand, services, gallery and booking call to action through a clean and minimalist interface.

This project was developed as part of my web development portfolio, with the goal of practicing front-end development and creating a complete website from scratch.

## ✨ Features

- Modern and minimalist visual design
- Hero section with a clear booking call to action
- Services section
- Image gallery
- About section
- Appointment booking section
- Clean and structured navigation
- Responsive layout for different screen sizes
